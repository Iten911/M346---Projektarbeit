# SaaS – Software as a Service

Definition:
Fertige Anwendung, läuft komplett beim Anbieter. Du nutzt sie im Browser oder per App, Updates kommen automatisch.

Beispiel:
Eine Firma nutzt Microsoft 365 für E-Mail und Office, ohne eigenen Mailserver.
